# Interactive Scientific Simulation and Data Visualization Tool for Wave Phenomena Using Python

An interactive 3D scientific simulation of wave propagation developed using Python, NumPy, and Matplotlib. The program visualizes a radially propagating water-wave surface while allowing the user to dynamically modify the wave frequency and amplitude through interactive sliders.

## Features

- Interactive 3D visualization of wave propagation
- Real-time animation of the wave surface
- Adjustable wave frequency
- Adjustable wave amplitude
- NumPy-based numerical computation
- Matplotlib-based scientific visualization
- Times New Roman scientific-style presentation
